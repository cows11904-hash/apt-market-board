# 시세나침반

서울 25개 자치구의 아파트 검색, 단지 기본 정보, 매매 실거래와 지도를 한 화면에서 조회합니다. 지역·단지명·법정동·전용면적·실거래 가격 상한·계약월·거래 유형을 공통으로 적용하고, `실거래 내역`과 `단지 · 지도` 탭으로 표시 방식을 바꿉니다.

단지 목록이나 거래 내역의 단지명을 누르면 세대수·동수·사용승인일·주차대수·세대당 주차·난방방식·복도유형·분양형태·주소·시공사와 실거래를 함께 확인할 수 있습니다. 기존 `quotes.html` 링크는 검색 조건을 유지하며 통합 화면으로 이동합니다. 현재 화면에서는 호가를 제공하지 않습니다.

## 실행

Node.js 22 이상에서 실행합니다.

```bash
npm ci --ignore-scripts
npm run fetch:complexes
npm test
npm run build
python -m http.server 8000 --directory dist
```

첫 실행의 `fetch:complexes`는 서울시 공식 공개 JSON을 받아 `data/complex-profiles.json`을 만듭니다. 별도 인증키가 필요하지 않습니다. 실패하면 기존 성공 자료를 유지합니다. 첫 수집도 실패하면 빌드를 완료하지 않아 불완전한 자료가 게시되지 않습니다.

## 출처와 연결

- 실거래: [국토교통부 아파트 매매 실거래가 상세 자료](https://www.data.go.kr/data/15126468/openapi.do). 현재 월과 직전 3개월의 매매 신고를 수집하며 해제 신고와 명시적 무상 이전을 제외합니다. 모든 가격에 출처와 확인일을 표시합니다.
- 단지 정보: [서울특별시 공동주택 아파트 정보](https://data.seoul.go.kr/dataList/OA-15818/S/1/datasetView.do), 공공누리 제1유형(출처표시). 공개 다운로드 자료에서 필요한 단지 항목만 보존하고 전화번호·팩스·고용보험번호 등은 게시 자료에서 제외합니다.
- 단지 정보는 같은 자치구와 법정동 안에서 단지명을 대조합니다. 공백·괄호·아파트 접미사와 법정동 접두사 차이를 정규화하고, 여러 후보·서로 다른 차수·건축연도 충돌은 추정 연결하지 않습니다.
- 공식 기본 정보에 등록된 단지는 수집기간의 실거래가 없어도 검색됩니다. 공란·0 등 확인되지 않은 주차대수는 `미확인`으로 표시합니다. 세대당 주차는 확인된 총주차대수 ÷ 전체 세대수로 계산합니다.
- 지도는 OpenStreetMap과 서울시 제공 단지 좌표를 사용합니다. 좌표가 없으면 지역 범위를 표시합니다. 카카오맵 원문 링크도 제공합니다. 지역 범위는 SGIS 및 기존 경계 자료를 유지합니다.

## GitHub Pages 운영

`.github/workflows/update-trades.yml`은 `main` 변경, 수동 실행, 매일 06:17 KST 예약 실행 때 검증과 수집 후 GitHub Pages에 배포합니다. 예약 실행은 지연될 수 있습니다. 기존 사이트의 공개 범위를 유지합니다.

1. 저장소 **Settings → Pages → Build and deployment → Source**를 **GitHub Actions**로 설정합니다.
2. 공공데이터포털에서 실거래 API 활용을 신청하고 인증키를 저장소 Secret `MOLIT_SERVICE_KEY`로 등록합니다.
3. **Actions → Publish 시세나침반 → Run workflow**로 수동 실행할 수 있습니다.

매 실행에서 서울시 단지 정보를 수집한 뒤 테스트하고, 국토교통부 거래 자료를 수집합니다. 검증된 스냅샷을 기록한 후 빌드 파일을 배포합니다. 새 자료의 페이지·월별 합계·수집 범위를 검산하고, 단지 정보가 직전의 80% 미만으로 감소하면 기존 성공 자료를 유지합니다.

`KAKAO_MAP_JAVASCRIPT_KEY` 변수가 있으면 기존 카카오 지도 SDK를 사용할 수 있습니다. 값이 없어도 OpenStreetMap과 서울시 단지 좌표로 지도가 동작합니다. 브라우저에는 수집 인증키나 공급 피드 인증값이 포함되지 않습니다.

## 공유 링크와 데이터 안전

`?gu=11410&area=84&q=홍은벽산`처럼 검색을 공유하고, `view=complexes`로 지도 보기를 지정합니다. 선택 단지·계약월·거래 유형·가격 상한도 주소에 유지됩니다. CSV는 현재 검색 조건의 거래를 내보내며, 서울 전체를 조회할 때도 실제 자치구명을 유지합니다.

단지 목록은 검증한 실거래 및 기본 정보로 생성하고 파일 해시로 연결합니다. 지역 거래 파일의 버전과 합계를 검사하고 오래된 자료는 갱신 지연을 표시합니다. 같은 조건의 별개 거래는 삭제하지 않습니다.

CSP는 HTML의 자원 로드 전에 적용됩니다. 스크립트와 데이터는 자체 출처로 제한하며 지도에 필요한 타일 이미지와 스타일만 추가 허용합니다. GitHub Pages의 응답 헤더 제약은 그대로 적용됩니다. CSV 문자열의 수식 시작 문자를 완화하는 기존 처리도 유지합니다.
