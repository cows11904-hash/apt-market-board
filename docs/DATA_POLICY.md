# 시세나침반 데이터 운영 정책

## 매매 실거래

- [국토교통부 아파트 매매 실거래가 상세 API](https://www.data.go.kr/data/15126468/openapi.do)는 신고된 매매가 출처입니다. 데이터 포털에는 무료이며 이용허락범위 제한 없음으로 표시되어 있습니다. 조회에는 발급된 인증키가 필요합니다.
- 증여·상속·무상 이전은 매매 API의 조회 대상에서 제외됩니다. 무상 이전 등 거래 원인이 명시된 응답도 제외합니다. `cdealType`과 `cdealDay`로 해제 신고를 걸러냅니다. 직거래는 신고에 들어 있는 구분을 그대로 표시합니다. [국토교통부 실거래가 FAQ](https://rt.molit.go.kr/pt/bbs/faqList.do?mobileAt=&qnaProcessSttusCode=1)
- 계약일, 전용면적, 층, 가격이 같은 신고도 서로 다른 세대의 정상 매매일 수 있습니다. 각 신고를 유지하고 월별 원자료와 정상 매매, 해제, 비매매의 건수가 일치하는지 검산합니다.
- 계약일과 API 확인일은 다릅니다. 매매 신고에는 계약일부터 30일의 시차가 있을 수 있고, 이미 표시된 계약도 이후에 정정되거나 해제될 수 있습니다. 공개 필드로 거래 당사자의 관계를 확인할 수 없습니다.
- 거래 가격은 만 원 단위의 공식 응답을 원 단위로 환산합니다. 전용면적은 공식 응답의 ㎡ 값을 사용합니다. 구·계약월별 JSON과 화면 및 필터링한 전체 CSV는 같은 정상 매매 행을 사용합니다.

공개 자료를 확인한 시점은 2026년 11월 13일입니다. 개별 매물 가격의 공개 재배포까지 허용하는 공급원은 확인되지 않았습니다.

## 호가 게시 요건

제공 계약에는 웹 화면과 공개 JSON에 표시 가능한 항목, 원본 링크, 재배포 및 캐시 보유기간, 삭제 요청 대응, 광고주·광고의 필수 표시 항목을 확인합니다. 정적 Pages 사이트의 JSON 파일은 누구나 내려받을 수 있습니다. 원본 사이트 링크는 사용자가 선택할 때 이동하며 서비스에서 가격을 자동으로 읽어오지 않습니다.

### 피드 연결

1. `data/listings.json`의 `providers`에 `id`, `name`, `publicRedistributionAllowed: true`, `approvedOn`, `validThrough`를 기록합니다. 두 날짜는 `YYYY-MM-DD`이며 공개 가능한 승인 범위만 등록합니다. 수집하는 원자료와 인증 정보는 저장소에 올리지 않습니다. 이 파일의 `listings`는 피드를 쓰지 않는 기존 정적 게시 방식과의 호환을 위해 유지합니다. 커밋 이력까지 공개할 권리가 확인된 행에만 이 방식을 사용합니다.
2. 공급 데이터나 공급자별 변환 프로그램에서 서울 아파트 매매 개별 매물 전체를 `application/json` 응답의 `listings` 배열로 전달합니다. 각 행에 `propertyType: "apartment"`, `transactionType: "sale"`, `providerId`, `listingId`, 5자리 `districtCode`, `aptName`, `areaM2`, 원 단위 `askWon`, 인증이 필요 없는 HTTPS `sourceUrl`, `verifiedAt`, `expiresAt`, `status` (`active` 또는 `withdrawn`)가 필요합니다. `dong`, `building`, `floor`는 공개 권한이 있는 경우 전달합니다. 시각은 밀리초를 포함한 UTC ISO 8601 형식으로 저장하고 화면은 한국 날짜를 표시합니다. `verifiedAt`은 공급자가 해당 가격과 매물 상태를 마지막으로 확인한 시각입니다. 피드는 증분 응답 대신 현재 전체 목록을 보냅니다.
3. GitHub Actions 저장소 Secret `LISTINGS_FEED_URL`에 HTTPS 피드 주소를, 인증이 필요한 경우 `LISTINGS_FEED_TOKEN`에 Bearer 값을 등록합니다. 빌드가 피드를 조회한 뒤 활성 지역의 유효 매물만 구별 공개 파일로 만들고, 이 파일은 Pages에만 배포합니다. 피드의 승인 주장과 계약에 없는 필드는 공개 출력에 사용하지 않습니다. 연결된 피드가 실패하면 그 매물을 숨기고 페이지에 수집 실패를 표시합니다.

철회·만료된 매물과 새 전체 응답에서 빠진 매물은 다음 배포의 공개 파일에서 제외합니다. 열린 화면은 렌더링할 때 유효기간을 다시 확인합니다. 다음 수집 전 가격 변경이나 철회가 반영되지 않을 수 있고, 여러 중개사가 같은 세대를 올리면 별개 매물로 보일 수 있습니다.
