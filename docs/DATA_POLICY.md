# 시세나침반 데이터 운영 정책

## 매매 실거래

- [국토교통부 아파트 매매 실거래가 상세 API](https://www.data.go.kr/data/15126468/openapi.do)는 신고된 매매가 출처입니다. 데이터 포털에는 무료이며 이용허락범위 제한 없음으로 표시되어 있습니다. 조회에는 발급된 인증키가 필요합니다.
- 증여·상속·무상 이전은 매매 API의 조회 대상에서 제외됩니다. 무상 이전 등 거래 원인이 명시된 응답도 제외합니다. `cdealType`과 `cdealDay`로 해제 신고를 걸러냅니다. 직거래는 신고에 들어 있는 구분을 그대로 표시합니다. [국토교통부 실거래가 FAQ](https://rt.molit.go.kr/pt/bbs/faqList.do?mobileAt=&qnaProcessSttusCode=1)
- 계약일, 전용면적, 층, 가격이 같은 신고도 서로 다른 세대의 정상 매매일 수 있습니다. 각 신고를 유지하고 월별 원자료와 정상 매매, 해제, 비매매의 건수가 일치하는지 검산합니다.
- 계약일과 API 확인일은 다릅니다. 매매 신고에는 계약일부터 30일의 시차가 있을 수 있고, 이미 표시된 계약도 이후에 정정되거나 해제될 수 있습니다. 공개 필드로 거래 당사자의 관계를 확인할 수 없습니다.
- 거래 가격은 만 원 단위의 공식 응답을 원 단위로 환산합니다. 전용면적은 공식 응답의 ㎡ 값을 사용합니다. 구·계약월별 JSON과 화면 및 필터링한 전체 CSV는 같은 정상 매매 행을 사용합니다.

## 매물 호가 공급원 조사

공개 자료를 확인한 시점은 2026년 11월 13일입니다. 개별 매물 가격의 공개 재배포까지 허용하는 공급원은 확인되지 않았습니다.

| 확인 대상 | 자료 범위와 이용 가능성 |
|---|---|
| 공공데이터포털 국토교통부 API | 아파트 매매 신고 상세 자료를 제공합니다. [API 안내](https://www.data.go.kr/data/15126468/openapi.do) |
| 한국부동산원 부동산통계 API | 주택가격동향·실거래가격지수 등 통계를 제공합니다. 개별 매물 ID와 현재 광고 가격은 공개 API 항목에서 확인되지 않습니다. [API 안내](https://www.data.go.kr/data/15134761/openapi.do) |
| 네이버페이 부동산 | 제공사 게시정보의 무단 복제·배포·전송을 제한합니다. 개별 호가 제공은 권리자의 허락과 계약 범위 확인이 필요합니다. [네이버페이 부동산 하단 안내](https://pre.land.naver.com/complexes/6028506/9048275) |
| 부동산R114·한국공인중개사협회 | 협회의 매물 DB 제공 협약 사례가 있습니다. 시세나침반의 개별 가격 공개에 적용되는 API나 재배포 조건은 별도 확인이 필요합니다. [협회 발표](https://seoul-n.kar.or.kr/pnews/karnewsview.asp?karnews=810) |
| 개업공인중개사 직접 공급 | 본인이 게시할 권한을 가진 자료의 제공 계약을 맺는 방법입니다. 공개 범위, 필수 표시 항목, 철회·정정, 확인 주기와 개인정보 취급을 검토한 뒤 연동합니다. [공인중개사법 제18조의2](https://www.law.go.kr/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1032085527) |

## 호가 게시 요건

`data/listings.json`의 `providers`에는 제공처 ID·표시명·공개 재배포 승인 여부·승인 시작일·만료일을 기록합니다. `listings`에는 제공처와 매물 ID, 시·군·구 코드, 단지명, 전용면적, 호가(원), HTTPS 원본 URL, 확인 시각, 유효 시각, 게시 상태가 필요합니다. 시각은 UTC ISO 8601로 저장하고 화면은 한국 시각을 사용합니다. 제공처 승인과 매물 유효기간이 모두 유지되는 행만 화면에 노출합니다.

정적 JSON과 공개 저장소의 커밋 이력도 계약상 공개 범위에 포함됩니다. 원본 링크, 복제·재배포, 캐시 보유기간, 삭제 요구 대응, 광고주·광고의 필수 표시 항목을 문서로 확인한 후 등록합니다. 기한 만료와 철회 자료는 다음 배포에서 공개 JSON에서도 제거합니다. 같은 ID를 다시 확인한 경우에만 이전 호가와 비교하며, 광고가 사라진 이유를 실거래 성사로 추정하지 않습니다.
